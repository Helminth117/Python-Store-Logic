# Python Store Logic 💰 (RPG Edition)

Este repositorio contiene un sistema robusto de gestión de inventario y transacciones desarrollado en Python. La lógica aplicada incluye validaciones de stock, gestión de clientes y reportes estadísticos.

## 🚀 Características Técnicas
- **Gestión de Inventario Dinámico:** Uso de diccionarios anidados para manejar stocks, precios y metadatos (stats de armas, rareza).
- **Lógica de Transacciones Segura:** Validación de existencia de clientes, stock disponible y balance de oro antes de procesar ventas.
- **Reportes Estadísticos:** Generación de métricas en tiempo real como valor total de stock, item más caro/barato y mejor cliente.
- **Historial de Ventas:** Registro detallado de transacciones por cliente y global del día.
