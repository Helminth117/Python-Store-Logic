<h1 align="center">Python Store Logic</h1>

<p align="center">Inventario, ventas y estadísticas de la tienda de un juego de rol.</p>

<p align="center">
  <img src="https://img.shields.io/badge/Python-3.10%2B-2B2B2B?style=flat-square&labelColor=0D0D0D&logoColor=F5F5F5&logo=python" alt="Python 3.10+">
</p>

Script de práctica sobre estructuras de datos en Python: el inventario y los clientes son
diccionarios anidados (precio, existencias, rareza, estadísticas del objeto, oro de cada cliente).

- **Compras** que comprueban que el cliente exista, que haya existencias y que le alcance el oro.
- **Inventario** con filtro por tipo: arma, armadura, consumible o accesorio.
- **Altas** de objetos nuevos.
- **Estadísticas:** valor total del inventario por tipo, objeto más caro y más barato, total
  recaudado en el día y mejor cliente.

## Ejecutar

```bash
python main.py
```

Ejecuta una demostración con varias compras y muestra los informes. En la consola de Windows usa
`python -X utf8 main.py` para que se vean bien los recuadros.
